# 微软输入法词条导入卡死解决方案

**问题**：Win10 微软拼音导入了数百万条自定义短语后，设置界面会无限卡死，连“清空”都打不开。

**解决办法**：直接删掉微软拼音的自定义短语词库文件。

1. 打开文件夹：  
   `C:\Users\你的用户名\AppData\Roaming\Microsoft\InputMethod\Chs`

2. 按“修改日期”排序，找到出问题那天生成的文件。

3. 删除所有以 **`ChsPinyin`** 开头的 **`.lex`** 文件，例如：  
   `ChsPinyinEUDP.lex`

4. 如果提示文件被占用、删不掉：
   - 先去“区域和语言 → 中文 → 选项 → 键盘”里删除微软拼音输入法；  
   - 如果删不掉，可以先添加“微软五笔”再删微软拼音；  
   - 还不行就在任务管理器里结束占用它的进程，比如 `ChsIME.exe`。

5. 最后重新把微软拼音添加回来即可。

**不用迁移账户，也不用重装电脑。**  
另外有人反馈：如果只是点了清除，也可以多等几分钟，可能自己会清完。
