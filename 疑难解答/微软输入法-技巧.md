# 微软输入法-技巧

### 一、生僻字输入：U 模式（核心）

**操作**：中文状态下按 `U`（双拼为 `Shift+U`），然后：

| 方式     | 规则                                    | 例子                                           |
| -------- | --------------------------------------- | ---------------------------------------------- |
| **拆分** | `U` + 各部件拼音                        | “叕” → `uyouyouyouyou`；“燚” → `uhuohuohuohuo` |
| **笔画** | `U` + 笔顺字母：横 h、竖 s、撇 p、捺 n、折 z | “少” → `uspnp`；“十” → `uhs`                   |
| **混合** | 拆分与笔画混用                          | “数” → `ulouphph`（娄+攵的笔画）               |
| **符号** | `UU` + 类别首字母                       | 标点 `uubd`、单位 `uudw`、数学 `uusx`          |

**⚠️ “笙”字特殊处理**：微软 U 模式无法用拼音 `zhu` 拆出竹字头（⺮），输入 `uzhusheng` 会失败。**正确代码是 `uphd`**（撇、横、点），在候选栏翻页即可找到“笙”。

> 所有 U 模式输入时，候选字旁会 **标注拼音**，边打边学读音。

### 二、V 模式：数字与格式转换

按 `V`（双拼为 `Shift+V`）后输入数字或算式：
- `v1200` → 壹仟贰佰					`v2026.9.7` → 二 〇 二六年九月七日
- `v12*12` → 144（直接出计算结果）        **编码输入**：`VUC6D3E` 或 `VGBC5C9` 均可打出“派”字（Unicode/GB-18030）

### 三、效率功能

**1. 人名模式**：姓名拼音+ `；` + `R`（双拼：姓名拼音+`Shift+；` + `R`），提高 `冷门姓名` 出现在候选词的排序次序
**2. 自定义短语**：设置 → 时间和语言 → 语言 → 中文 → 微软拼音 → 词库和自学习 → 添加自定义短语。
可将地址、邮箱等设为缩写（如 `dz` → 完整地址），支持 `$year$`、`$month$` 等日期变量。
**3. 内置文本替换**：

- `s'j` → 当前时间	`r'q` → 当前日期	`n'l` → 农历日期	 `p'f` → 平方符号 ²

**4.快捷操作**：`win＋v` 打开剪切板；`Win + .`（句号） 或  `Win + ;`（分号）。这会打开 Windows 的 Emoji 面板
